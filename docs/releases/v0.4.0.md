# RenPy Localization Studio v0.4.0

本版本整理翻译工作区的信息层级和深色主题，并发布前两轮已完成的批量校对与迁移功能。

## 界面与操作

- 翻译顶栏收敛为两行常用操作，低频工具移入「更多」，搜索字段及审校、译文、文件范围筛选集中在弹出层。窄窗口自动使用紧凑入口。
- 修复空列表重复出现工具按钮，空状态只保留提示及适用的清除筛选入口。
- 重组设置与保存菜单；强制覆盖仍需确认，取消入口只在任务运行时显示。
- 导航与检查器支持拖动调宽，重启后恢复；画面预览默认折叠并记住展开状态和比例。
- 检查器优先保证译文编辑空间，提供字数比较、上/下一条和保存入口。
- 补齐深色表格、勾选框、展开控件、子窗口标题栏及键盘焦点，自动调整强调色按钮的文字对比度；适配系统高对比度和关闭动画设置。

## 翻译与校对

- 批量复用完全相同原文的唯一有效译法，支持预览、选择和撤销。
- 项目术语表、校对状态与备注、字段及正则搜索、可预览并撤销的批量替换。
- UTF-8 CSV 校对导出与基线保护回填、旧版译文相似候选迁移、外部文件三方对比。
- 按项目和语言恢复浏览与筛选，大项目后台筛选及可取消质量检查。

## 下载与运行

- `framework-dependent.zip`：需要 .NET 10 Desktop Runtime x64，包体较小。
- `self-contained.zip`：自带 .NET Runtime，解压后运行 `RenPyLocalizationStudio.exe`。
- 两个包均为 Windows x64，包含校验过的隔离 Python、unrpyc 和安全 RPA 读取器；每个 ZIP 附 SHA-256 文件。

术语、校对记录和界面布局保存在本机用户设置；工作恢复不恢复未保存草稿。替换、校对回填及迁移请先核对预览，迁移候选需要人工确认。
