# 校对工作流验证（2026-10-08）

本轮包含术语表、校对状态与备注、高级搜索与替换、CSV 校对回填、旧版译文迁移及外部修改三方对比，以及前一轮批量复用、工作恢复和后台筛选。

## 功能验证

- Release 测试 178 项全部通过，新增 15 项覆盖术语边界、状态失效及恢复、语言隔离、字段搜索与正则超时、CSV 多行转义及重复/过期数据、替换结构保护与撤销、迁移候选选择及取消、外部双方修改、文件增删改检查、磁盘读取失败及共享译文取舍。
- 实际 WPF STA 控件验证：新工具四个页签在 720 / 1100 像素下渲染，实际操作术语保存、校对状态下拉框、替换复选框、应用及撤销；复查原有主窗口在 720 / 1000 / 1500 像素下的布局和快捷键。
- 此处 GUI 验证使用本机临时夹具与独立验证程序，不属于自动化 CI；它不等于所有真实游戏兼容性或发布后的使用验收。
