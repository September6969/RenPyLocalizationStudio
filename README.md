# RenPy Localization Studio

当前版本：**v0.3.11**。

RenPy Localization Studio 是一个面向 Ren’Py 人工本地化流程的 Windows 桌面工作台。它把 tl 生成、剧情流翻译、额外文本、替换规则、`zzz.rpy` 补丁以及解包/反编译安全服务收敛到同一项目界面。

## 主要能力

- 识别 `label`、`menu`、`if/elif/else`、`jump`、`call`、`return` 和文件内自然流程。
- 隔离 `$`、`python`、`init python`、`init` 与 `screen` 代码块，不执行游戏代码。
- 将菜单字符串虚拟挂回实际分支；相同 `old` 始终共享一个译文，并显示影响位置。
- 菜单字符串的官方行号发生小幅偏移时，会在同一源码文件内按唯一 `old` 回退绑定；多个候选仍作为歧义项处理。
- 单击剧情流中的 `jump` 或 `call` 行，或选中后按 `Enter`，可直接定位到对应 `label`；搜索条件遮挡目标时会自动清除搜索。
- 翻译工作区新增「质量检查」视图，集中检查空译文、占位符/标签差异、共享字符串冲突与同原文不同译法；每条问题直接关联可编辑译文，选中后可修改，`Enter` 聚焦编辑器。复杂原始块会提示人工核对。
- 可按待译、已译、冲突、已修改筛选，并限定文件或 Label 查看当前范围的翻译进度；可与关键词组合，清除筛选恢复全部。待译与共享冲突分开列出，已译表示内容非空且无共享冲突，不代表质量校验通过。
- 编辑时保留当前结果，避免条目在输入中消失；出现更新提示后点击「刷新结果」重算筛选和质量清单。质量检查仅检查可静态判断的问题，不代替语义校对。
- 检查器提供「项目内相同原文」译文复用：按完全一致的原文列出已有译法、使用数量及来源，人工核对语境后点击采用，支持撤销与正常保存。候选随项目重新分析重建，读取当前内存中的最新译文；排除冲突、空白、复杂原始块和占位符不匹配内容。
- 主区域始终提供搜索框与视图切换；`Ctrl+F` 聚焦搜索、`Ctrl+S` 保存译文、`F8` 定位下一条待译。这些快捷键仅在翻译工作区生效。
- 占位符标签可点击插入到译文光标处，也可替换选中文字，支持 `Ctrl+Z` 撤销；只读期间禁用。
- 窄窗口仍可打开翻译检查器；空间不足时优先保留正文与编辑器，按钮明确显示「打开/收起检查器」。
- 翻译列表提供「下一条待译」，在当前搜索结果内循环定位空译文或冲突译文，并直接聚焦编辑器。搜索显示匹配数量，按 `Esc` 可清除；空列表会提示原因与下一步。
- 画面预览可收起以扩大剧情列表，展开时恢复本次视图中调整过的分栏比例；侧栏标签在较窄窗口中自动换行。
- 左侧 label 列表支持单击、双击或按 `Enter` 定位，重复定位当前选中项同样生效。
- 在译文输入框中按 `Alt+↑` / `Alt+↓` 可切换到上一条或下一条可编辑译文，并继续保持输入焦点。
- 单独索引 screen/界面字符串、未绑定翻译与静态分析诊断。
- 普通 strings、screen 文本和数据文本只进入字符串表；“未绑定剧情”仅显示未能挂接的 dialogue 翻译块。
- 检查插值、百分号占位符和 Ren’Py 文本标签差异。
- 可写入幂等的 `RFT-FLOW-BEGIN/END` 流程注释。
- 原子保存、外部修改检测、最近一次 `.rls.bak` 备份，并继承原文件 BOM 与换行风格；可经二次确认强制覆盖外部修改，且不会绕过结构校验。
- 通过本机 Ren’Py SDK 预检或增量生成 tl，后台捕获日志并支持取消。
- 按剧情路径、源文件或 label 浏览同一流程图。
- 可在代码行右键添加/移除书签，并通过“书签”选项卡快速筛选和定位；书签按项目和语言保存在用户设置中，重新打开后恢复；源码变化时仅接受明确位置或唯一上下文匹配，无法定位的书签会提示失效。
- 在“书签”视图单击、双击、按 `Enter` 或使用“定位原代码”可回到完整剧情流中的原始文件与行号。
- `Alt+↓` 遇到可解析的 `jump` 时会跟随目标 label，直接进入目标分支的下一条可编辑译文。
- “更多设置”可选择开启译文防抖自动保存（默认关闭；停止输入约 0.9 秒后写入）；项目、分组和上次选中条目会保存到用户设置并在下次分析后恢复。
- `Alt+←` / `Alt+→` 在编辑器中保留单词移动；离开编辑器后会拦截，避免误触历史或窗口导航。
- 扫描 Character、screen、input、notify、define/default 等额外文本，人工确认后写入受管补丁。
- 校验精确 replace 规则，并使用受管区块生成 `zzz.rpy`。
- 解包/反编译服务强制项目内路径、冲突跳过和源文件保留策略。RPA 与 RPYC 都会使用受限反序列化器解析不可信索引或 AST；不会执行游戏脚本，但解析复杂二进制格式仍存在第三方解析器风险。
- 批量移除文件名前缀，默认兼容 `x-`，执行前显示完整映射并阻断同名冲突与预览后的外部修改。
- YAC 图片压缩工作流支持 PNG、JPEG 和静态 WebP；默认输出到项目内独立目录，也可显式选择原位替换并创建 `.rls.bak`。
- 深色 IDE 工作台、Mica 渐进增强、三套强调色与自定义色、AvalonEdit 纯文本编辑器和占位符令牌栏。

## 批量复用与工作恢复

- 翻译工具栏的「批量复用」先展示预览，默认采用当前视图和筛选范围，可切换为整个项目当前语言。仅填空译文，只采用完全相同原文的唯一有效译法；已有内容、冲突、复杂块及无有效候选的条目会列出跳过原因。
- 在预览中逐项勾选，选中一行可查看完整原文、译文、来源和影响位置。应用前会核对预览是否过期，共享字符串只处理一次。应用遵循原有手动/自动保存设置。
- 「撤销批量编辑」撤销最近一次批量操作；保存后仍可撤销，撤销结果需要再次保存。目标被再次编辑后会阻止撤销，切换项目、语言或主动重新分析会清空批量历史。编辑器的 Ctrl+Z 保持原有行为。恢复空译文触发结构警告时，自动保存仍会阻断，需要人工核对后手动保存。
- 视图、分组、书签、关键词、状态筛选、文件/Label 范围和浏览位置按项目及语言分别恢复。筛选隐藏上次位置时保留筛选；失效范围恢复为全部范围。此功能不恢复未保存草稿。
- 超过 2,000 个投影条目时，筛选在后台执行，关键词输入合并约 200 毫秒内的连续修改；大型项目的质量检查可取消。计算期间保留上一轮列表，编辑后提示刷新，过期结果不会覆盖新项目或新译文。

可复现的性能测量与结果见 [性能验证记录](docs/performance-20261007.md)。

## 术语、校对与版本迁移

- 「术语表」按项目和语言保存推荐译名与禁用译名（英文分号分隔），在编辑器提示和质量检查中显示问题。术语和校对记录存放在本机用户设置中；不会写入游戏脚本。
- 「校对」维护待校对、已校对、需讨论及备注。译文或原文变化会退回待校对，保留备注；主列表可筛选校对状态。搜索可限定原文、译文或位置，支持区分大小写和有超时限制的正则，搜索选项随工作区恢复。
- 「替换 / 校对表 / 迁移」先生成预览，可选择当前筛选范围或整个项目当前语言。查找替换只改译文，逐项显示修改前后内容，拦截占位符和标签不匹配；应用后支持撤销最近一次批量编辑。
- 导出当前语言校对表后，以 UTF-8 CSV 保存，编辑 `Translation`、`Status`、`Note` 列，保留 `Language`、`Key`、`Original`、`Baseline`。文本列统一加单引号防止表格软件执行公式，导入时去除一个前导单引号。回填核对标识、原文、语言和导出基线，过期或重复条目不覆盖当前工作。状态支持「待校对 / 已校对 / 需讨论」；未知状态按待校对处理。
- 旧版译文迁移使用旧项目导出的校对表，只为当前空译文推荐最多三种相似原文译法。使用有上限的候选检索，不保证找出所有相似句；默认不勾选，须人工核对语境，每个目标只能选一种译法。
- 「外部对比」重新读取磁盘，结合分析时基线比较本地与磁盘译文。单方修改默认保留修改方；双方修改需明确选择。被删除、原文变化、复杂原始块等无法安全保留本地的情况显示原因，只能采用磁盘版本。应用前再次检查磁盘增删改及本地变化，过期对比必须重做；应用只更新工作区，核对后点击保存。磁盘上的其他内容以新版本为准。

本轮校对功能与性能复核见 [验证记录](docs/editorial-validation-20261008.md)。

## 使用

1. 启动 RenPy Localization Studio，选择包含 `game` 目录的项目根目录。
2. 可使用“TL 预检/生成 TL”，或直接选择已有目标语言。
3. 选择 `game/tl/` 下的语言并点击“分析”。
4. 在“剧情流”或“字符串表”中选择条目并编辑译文。
5. 点击“保存”，或点击“保存并刷新注释”同步流程边界注释；遇到确认无误的外部修改冲突时，可从“更多设置”选择“强制覆盖外部修改”。

工具不会执行游戏 EXE、不会删除 `.rpa/.rpyc/.rpymc`，也不会自动翻译文本。跨文件的无显式跳转自然落入会显示为“文件结束”。

## 开发与验证

```powershell
dotnet restore .\RenPyLocalizationStudio.sln
dotnet test .\RenPyLocalizationStudio.sln -c Release
dotnet run --project .\src\RenPyLocalizationStudio.App\RenPyLocalizationStudio.App.csproj
```

使用本机 Ren’Py SDK 对临时夹具执行安全 lint：

```powershell
.\scripts\verify-sdk-lint.ps1 -SdkExe <RenPy-SDK目录>\renpy.exe
```

发布 Windows x64 程序：

```powershell
.\scripts\publish.ps1
# 可选：生成无需预装 .NET Desktop Runtime 的自包含目录
.\scripts\publish.ps1 -SelfContained
```

默认发布目录为 `artifacts\win-x64`。框架依赖包要求目标电脑安装 **.NET 10 Desktop Runtime x64**；`-SelfContained` 生成的包无需预装 Runtime，但体积更大。两种包都只支持 Windows x64，并包含校验过的隔离 Python、unrpyc 与内置安全 RPA 读取器。

生成可发布 ZIP 与 SHA-256：

```powershell
.\scripts\publish.ps1 -Package
.\scripts\publish.ps1 -SelfContained -Package
```
